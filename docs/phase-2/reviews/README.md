# Phase 2 Code Reviews

> 🗄️ **Doc status: HISTORICAL — superseded.** Dated snapshots, not edited
> after they're written; see [../../milestones.md](../../milestones.md#documentation-status-conventions)
> for what CURRENT/HISTORICAL mean project-wide.

Dated code-review reports produced during Phase 2. One file per run
(`YYYY-MM-DD-HHmm-review.md`), moved here from a repo-root `reviews/` folder
since every review to date happened during this phase. Each new review
checks the most recent prior report and carries forward what's resolved,
still open, or regressed; a review only reports findings, it never edits
project source itself.

- [2026-09-13-1516-review.md](./2026-09-13-1516-review.md) and
  [2026-09-13-1539-review.md](./2026-09-13-1539-review.md) were produced by
  a project-local `code-reviewer` subagent, since removed in favor of
  Claude Code's built-in review tooling (`/code-review`).
- [2026-09-13-code-review.md](./2026-09-13-code-review.md) was produced with
  the `mattpocock-skills:code-review` plugin skill.

All three are still accurate as a historical record of what each review
found at the time.
