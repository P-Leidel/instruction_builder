# Reviews

This folder holds reports produced by the `code-reviewer` subagent (`.claude/agents/code-reviewer.md`).

- One file per run: `YYYY-MM-DD-HHmm-review.md`.
- Each new review checks the most recent prior report here and carries forward what's resolved, still open, or regressed.
- These are review documents only — the agent that writes them never edits project source files.
